
# CyberSuraksha Prompt Comparison

## Objective

To compare two prompt versions (v1 and v2) for the CyberSuraksha chatbot.

## Evaluation Method

- Used 10 questions about online financial fraud.
- Tested each question with prompt v1.
- Tested the same questions with prompt v2.
- Compared the answers and confidence levels.

## Evaluation Criteria

1. Does the response contain valid JSON?
2. Is the answer based only on the available records?
3. Does the chatbot avoid inventing information?
4. Does it clearly identify missing information?
5. Is the answer simple and understandable?
6. Is the follow-up question useful?
